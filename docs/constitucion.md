# Constitución de PAGO FÁCIL

La constitución vigente está en **[`.specify/memory/constitution.md`](../.specify/memory/constitution.md)**. Este archivo solo apunta a ella para que se encuentre desde `docs/`.

Ese es el lugar donde la lee spec-kit: los comandos `/speckit-plan` y `/speckit-analyze` revisan cada plan contra sus principios. Para cambiarla, sigue la sección "Gobierno" de la propia constitución: un pull request que Hugo propone o aprueba y que revisa al menos otra persona del equipo.

La guía operativa para los agentes de IA está en [`AGENTS.md`](../AGENTS.md).
